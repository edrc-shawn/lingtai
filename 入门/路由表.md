# 灵台路由表

> 人类找域入口。看关键词定位话题归属域 → 读枢纽页入门。

| 域 | 路由关键词 |
|:---:|:-----------|
| `00-思考与认知` | 追问/认知/独立思考/判断力/心理/情绪/含人量 |
| `01-内容创作` | 公众号/短视频/抖音/小红书/选题/爆款/文案/自媒体/写作 |
| `02-成长与日常` | 个人成长/日常反思/自律/习惯 |
| `03-社会观察` | 社会观察/性别/面子/社会批判/规训/对立 |
| `04-身体与健康` | 减脂/增肌/运动/营养/健康 |
| `05-哲学与思想` | 哲学/权力/物理/文明/自由/时间/易经 |
| `06-商业与投资` | 创业/投资/金融/经济/变现/商业模式 |
| `07-工具与AI` | AI工具/编程/Obsidian/知识管理/算法 |
| `08-教育` | 教育/学习/育儿/费曼 |

> 初始化时 `python scripts/lingtai.py init` 会根据职业模板自动创建域目录。
> 你也可以自定义域——只要遵循 `NN-描述语` 命名规范。
