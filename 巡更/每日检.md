# 巡更·每日检

> 运行 lint + 反链追加 + 缺口检查 + 选题捕获。

## 核心约束

| 级别 | 类型 | 策略 |
|:---|:---|:---|
| 🔧 L1 自动修复 | 格式错误、死链接、反向链接缺失 | 自动修复 + 报告列出 |
| 👁 L2 只扫不修 | 孤立页、内容腐烂、语义漂移等需判断项 | 仅输出报告，不自动修改 |

## 流程

### 第 1 步：运行 lint

```bash
python scripts/lint_check.py
```

### 第 2 步：提取 24h 变更

通过 git log 获取最近 24h 变更：
```bash
git log --since="24 hours ago" --name-only --pretty=format:"%H %ai %s" --diff-filter=A
git log --since="24 hours ago" --name-only --pretty=format:"%H %ai %s" --diff-filter=M
```

列出新增的丹房页面 + 大修改页面，检查是否有与现有页面矛盾的信号。

### 第 3 步：反向链接追加

取第 2 步找到的最近 24h 新页，对枢纽页/独立概念页：

1. 提取新页主题词/标签
2. grep 全库找内容相关的已有丹房页（目标 5-10 条）
3. 在相关段落中用内联 `[[链接]]` 自然引用新页
   - 若旧页无自然交叉点 → 跳过，不强制引用

### 第 4 步：缺口检查

检查 lint 报告的断裂链接是否命中 `体检/对账.md` 已有缺口：
- 命中已有 → 维持原状态，不重复写入
- 未命中已有 → 新增行，标 ⏳ 推迟 + 编号（D001 起）

### 第 5 步：选题捕获

检查 24h 变更中是否有符合选题标准的素材（个人经历/真实体感/反转洞察 至少占一）。
符合 → 追加到选题池。不符合 → 跳过。

### 第 6 步：对话输出

在对话中按三级分层输出完整体检报告：

**🔴 严重**（不改系统会坏）：死链/缺口、缺 frontmatter
**🟡 警告**（影响体验但不致命）：死胡同/孤立、时效过期
**🟢 建议**（锦上添花）：链路 WARN、语义重叠

### 第 7 步：记录

追加 `日志.md` 一行：`[YY-MM-DD HH:MM] 体检 | 每日检——关键指标摘要 | → 自动化`

提交 Git。

## 输出参考指标

| 级别 | 指标 | 说明 |
|:--|:--|:--|
| 🔴 严重 | 缺口 | 死链接数 |
| 🔴 严重 | 下品 | FMPurity=下品 |
| 🟡 警告 | 死胡同 | 入度=0的丹房页 |
| 🟡 警告 | 孤立 | 全库无链接指向 |
| 🟡 警告 | 时效 | 页面过期提醒 |
| 🟢 建议 | 链路WARN | 原料缺丹房 wikilink |
